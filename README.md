# BCL Cold Chain Logistics Website

GitHub Pages-ready static website for the ITBT Live Class Exercise: Build a Digital Business App.

## Files
- `index.html` - one-page website with Home, About, Services, Dashboard, Tracking, Quote, Contact and Sources sections.
- `style.css` - responsive visual system and layout.
- `script.js` - interactive shipment tracking, quote estimator, dashboard chart filter and mobile navigation.
- `images/baiju-kumar-singh.jpeg` - owner photo supplied for the website.
- `assets/sample-quotation.pdf` - sample quotation template for demonstration.

## Requirement coverage from the class exercise
1. Home: business name, logo, purpose, description and Get a Quote button.
2. About Business: what the company does, target customers, service area and value proposition.
3. Services: six service modules with descriptions and commercial/price cues.
4. Dashboard: six KPIs and one chart/visualisation; demo values are clearly labelled as prototype data.
5. Contact / Enquiry: phone, email and quote form.
6. Working hyperlinks: section navigation, phone, email, source websites and sample quotation PDF.
7. Interactive business feature: demo shipment tracking + quote estimator.

## GitHub Pages
1. Create a new GitHub repository, for example `Baiju-Kumar-Cold-Chain-App`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, `images/`, and `assets/` to the repository root.
3. Go to **Settings -> Pages**.
4. Select **Deploy from a branch**, choose the main branch and root folder.
5. Save and open the live GitHub Pages URL.


## Interactive quotation feature
The Request a Quote section now calculates an indicative estimate from the customer's inputs and prepares a branded quotation layout. After submitting the form, the user can select **Print / Save PDF** and use the browser's PDF printer to save the quotation. The section also links directly to the public Maersk reference PDF used as source material.
